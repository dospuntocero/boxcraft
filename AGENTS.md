# Alias de adquisición de cajas

Cuando el usuario escriba `obtener <código Pacdora>` (por ejemplo, `obtener 15030101`), ejecuta el flujo completo de [skills/obtener-pacdora/SKILL.md](skills/obtener-pacdora/SKILL.md). El código identifica el modelo que se debe investigar; el ejemplo no ordena adquirirlo ahora.

Se aceptan opciones en lenguaje natural: medidas, unidades, material, espesor, pliego y alcance de integración. Conserva los valores iniciales de Pacdora cuando no se especifiquen. No pidas que el usuario vuelva a pegar el prompt. El alias tiene alcance en este proyecto.
