# Box acquisition alias

When the user enters `obtener <código Pacdora>` (for example, `obtener 15030101`), execute the complete workflow in [skills/obtener-pacdora/SKILL.en.md](skills/obtener-pacdora/SKILL.en.md). The code identifies the model to investigate; the example does not instruct you to acquire it now.

Natural-language options are accepted: dimensions, units, material, thickness, sheet size, and integration scope. Preserve Pacdora's initial values when unspecified. Do not ask the user to paste the prompt again. The alias applies within this project.
